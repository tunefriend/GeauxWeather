    Data & privacy

    Forecasts from Open-Meteo, radar from RainViewer, storms from NHC / NWS, places via OpenStreetMap Nominatim. No account, no analytics SDKs, no ads. See the privacy policy.

    Brave / Chrome extension

    Toolbar popup with live weather, city search, temperature badge, and a link to this site. Works in Brave and other Chromium browsers. No ads, no tracking.

    Install (unpacked):

    1. Download and unzip the extension
    2. Open brave://extensions
    3. Turn on Developer mode
    4. Click Load unpacked and select the geauxweather-brave folder
    5. Pin GeauxWeather from the puzzle-piece menu
    Download Brave extension Source on GitHub

    Linux desktop tray

    For Debian / Ubuntu / GNOME: install a top-bar tray icon that shows the temperature and opens this site. Also adds a GeauxWeather app launcher.

    One-line install:

    curl -fsSL https://geauxweather.com/linux/install.sh | bash

    Then start the tray:

    python3 ~/.local/share/geauxweather-widget/geauxweather_tray.py &
    Download .tar.gz Source on GitHub

    Pin the app: Activities → search GeauxWeather → right-click → Pin to Dash. Needs the AppIndicator GNOME extension (install script installs the package on Debian).
