GeauxWeather Linux tray

Panel temperature + weather condition for GNOME, KDE, XFCE, Cinnamon, MATE, Budgie, LXQt, and other AppIndicator desktops.

One-line install

curl -fsSL https://geauxweather.com/linux/install.sh | bash

Then start (or log out/in — it autostarts):

python3 ~/.local/share/geauxweather-widget/geauxweather_tray.py &

Download .tar.gz Full site section Source

What you get

  • Location from your network IP (not hard-coded to Louisiana)
  • °C by default outside the US (en_US → °F)
  • Config at ~/.config/geauxweather-widget/config.json (kept on reinstall)
  • A single autostart entry (no duplicate icons)
  • Drawn weather icons (no special emoji font required)
  • Tray menu: Location (detect / search city) · Units · Refresh · Open website

Update

Run the same one-line install again, then restart the tray:

killall geauxweather_tray.py 2>/dev/null || true
python3 ~/.local/share/geauxweather-widget/geauxweather_tray.py &

Your existing config is not overwritten.
